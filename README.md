# cpp-binary-search-tree

##Included Features
-Template-based implementation
-Recursive deletion
-Recursive insertion
-Search function
-Minimum and maximum locating
-Destructor-based memory management

#Files
-SearchTree-h -- BST implementation
-main.cpp -- test and demonstration

#Operations
-Insert node
-Remove node
-Search for value
-Find minimmum and maximum
-Check if tree is empty
-Print tree structure

##Build
Developed in Visual Studio 2022 using C++14.
